# Orbital Greenhouse

Run `npm run scenario -- --scenario orbital-greenhouse.json` after configuring an
explicit live model, or load Orbital Greenhouse with `npm run playground` to view
its 3D state. `--fixture` is available for headless developer checks.

The [spatial guide](../../docs/providers-and-spatial.md) documents frames, timing,
obstacles, host assumptions, and viewer/headless equality. This independent host
uses public `simkind/runner`, `simkind/format`, and `simkind/spatial` imports.
